# Behavior Monitoring & Analytics Platform

**Tools:** Full-Stack Web App | Python (Flask, Machine Learning) | SQL | JavaScript, React

This project is a full-stack platform for logging and analyzing personal behavioral metrics. Users can record data on a numeric rating scale, explore trends, and gain insights from interactive visualizations powered by statistical and machine learning methods.

## Features

- **Data Logging & Analytics:** Built a platform to capture personal behavioral metrics and provide actionable insights.  
- **End-to-End Pipeline:** Implemented a complete data pipeline from frontend input to backend storage to dashboard visualization, focusing on low latency and efficient server performance.  
- **Machine Learning & Statistics:** Applied correlation matrices, lag analysis, distribution modeling, time-series forecasting, and clustering to identify behavioral patterns.  
- **Interactive Dashboard:** Developed an intuitive dashboard for easy user engagement and data exploration.

## Objectives

- **Monitor and analyze behavior** over time with a structured, data-driven approach.  
- **Identify patterns and trends** using statistical and machine learning techniques.  
- **Provide an interactive experience** for users to explore their own data insights.
